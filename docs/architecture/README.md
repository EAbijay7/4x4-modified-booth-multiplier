# Architecture

The design implements a **4×4 Modified Booth multiplier** as a hierarchical transistor-level schematic in Cadence Virtuoso.

## Design Flow

```text
Modified Booth Algorithm
          ↓
Architecture Decomposition
          ↓
Transistor-Level Circuit Modules
          ↓
Reusable Schematic Symbols
          ↓
Hierarchical Integration
          ↓
Complete 4×4 Multiplier
          ↓
Connectivity / Verification
```

## Hierarchy

The exact module hierarchy will be documented from the project's Cadence screenshots. No circuit blocks are being assumed or fabricated in advance.

## Planned Evidence

- Top-level multiplier schematic
- Module-level schematics
- Reusable symbol views
- Hierarchical connections
- Cadence verification evidence
